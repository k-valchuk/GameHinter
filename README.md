# Game Hinter

Приложение на FastAPI для генерации подсказок.

## Описание

Это приложение разработано для генерации подсказок по уровням. Основной функционал доступен через REST API. Главный эндпоинт `/hints/{level_id}` возвращает подсказки для указанного уровня, а дополнительные эндпоинты предназначены для загрузки уровней или получения их списка.

## Требования для запуска

- **Docker** – для контейнеризации и запуска приложения.
- **Make** – для удобства запуска (если Make не установлен, можно воспользоваться командами Docker напрямую).
- **vpn** - так как API OPENAI может быть недоступно в некоторых регионах

## Преднастройка

1. Скопируйте содержимое файла `example.env` в новый файл `.env`:
   ```bash
   cp example.env .env
   ```
2. Откройте файл `.env` и укажите ваш `OPENAI_API_KEY`.

## Запуск приложения

### С использованием Make

Запустите следующую команду в терминале:
```bash
make up
```

### Без Make

Если Make не установлен, выполните следующие команды:

1. Постройте Docker-образ:
   ```bash
   docker build -t gamehinter .
   ```
2. Запустите контейнер, передав переменные окружения из файла `.env` и пробросив порт 8000:
   ```bash
   docker run --env-file=.env -p 8000:8000 -it gamehinter
   ```

## Использование

После запуска приложения, вы можете использовать API через Swagger UI:

- Откройте браузер и перейдите по адресу:  
  [http://localhost:8000/docs](http://localhost:8000/docs)  
  или  
  [http://0.0.0.0:8000/docs](http://0.0.0.0:8000/docs)

В Swagger UI доступны все endpoint'ы приложения:

- **`/hints/{level_id}`** — основной эндпоинт для получения подсказок по уровню.
- Дополнительные эндпоинты — предназначены для загрузки уровней или получения их списка.
